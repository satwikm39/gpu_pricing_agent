## Design Context

### Users
Technical students and instructors in a workshop/classroom setting learning about AI-driven dynamic pricing for B2B GPU leasing. They interact with the dashboard to understand how autonomous agents make pricing decisions, configure policies, and run simulated scenarios. The context is educational but the tool should feel professional — like a real deal desk, not a toy.

### Brand Personality
**Authoritative, Transparent, Precise.** The interface is a glass-box simulation — users need to trust the data, understand the agent reasoning, and feel confident adjusting policy levers. It should feel like a Bloomberg terminal's younger, more approachable sibling.

### Aesthetic Direction
- **Visual tone**: Industrial-utilitarian command center with editorial clarity. Dense but legible. Dark mode only.
- **References**: Bloomberg Terminal (density, authority), Linear (polish, restraint), Vercel dashboard (typography, spacing)
- **Anti-references**: Generic AI dashboards with neon glows, glassmorphism, gradient text. No "cool dark mode for coolness sake."
- **Theme**: Dark slate palette with restrained blue/purple accents. No gradients, no glows.

### Design Principles
1. **Clarity over decoration** — every element earns its space by conveying information
2. **Density with breathing room** — show more data, but use spacing rhythm to prevent overwhelm
3. **Typographic hierarchy is the UI** — size, weight, and space do the heavy lifting, not color or borders
4. **Consistent restraint** — if one section is quiet, all sections are quiet
